# SmartPrompter
SmartPrompter
本软件由gemini制作
智能提词器（SmartPrompter）安卓原生源码工程
一款专为主播、医生、短视频创作者打造的专业提词器 Android 原生应用。

🌟 核心功能特色
蓝牙耳机物理/触控按键遥控：
基于 Android ，支持 AirPods、华为、小米、索尼等各类蓝牙耳机。MediaSessionCompat
单击/双击捏合耳机（播放/暂停）：随时开始或暂停提词器滚动。
切歌按键（上一首/下一首）：微调滚动速度。
音量大小直接调节滚动速度：
拦截物理音量按键与监听 广播。android.media.VOLUME_CHANGED_ACTION
调大音量：提词速度实时加快 （+5 px/s）。
调小音量：提词速度实时减慢 （-5 px/s）。
拦截系统弹出的音量遮挡框，保证提词视野干净。
专业提词全特性：
毫秒级无级平滑垂直滚动（10 ~ 200 px/s）。
水平镜像翻转（支持专业分光镜/反射式提词架）。
视线对齐参考红线（确保眼神始终聚焦镜头）。
沉浸式纯黑全屏模式，自动保持屏幕常亮防息屏。
